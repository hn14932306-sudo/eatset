## 啟動

```bash

```

未設定 `EATSET_API_BASE_URL` 時啟動 Demo 模式。真實店家驗證依 [places-setup.md](places-setup.md) 設定後端金鑰，再以公開後端網址重建 App；不要把金鑰放入 Flutter、提交或貼到聊天。

- 修正詳情缺少繁體中文參數，以及同一家店更新詳情時重複載入照片。
- 靜態分析無問題；Flutter 97 項、Node 後端 11 項回歸測試通過。
- 照片仍是一般店家照片，尚未做到只挑評論食物照。未驗證 Android、實體 iPhone、不同地區的飯店排除涵蓋率、雲端部署及實際帳單費用。

重新啟動測試環境（保留本機 .env，不把內容貼到終端輸出）：

```bash
cd server
node --env-file=.env index.mjs
```

另一個終端從專案根目錄執行：

```bash
flutter run -d 15888AC2-B723-4CB6-834E-75C05DB7571C --debug --dart-define=EATSET_API_BASE_URL=http://127.0.0.1:8787
```

後端限額用完會顯示稍後重試。`node --env-file=.env usage.mjs` 可在 server 目錄查看不含金鑰的用量紀錄。App 在實體手機上需另設可連線的 HTTPS 後端，不能使用手機自身的 127.0.0.1。
